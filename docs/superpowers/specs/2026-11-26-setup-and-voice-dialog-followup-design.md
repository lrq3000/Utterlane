# Setup and voice dialog follow-up

## Interrupted model setup

Onboarding must distinguish an interrupted transfer with retained bytes from a restart. While reconnecting, show retained progress without claiming that downloading has already resumed. Once the host responds, the displayed progress follows the bytes actually used. For checksum-pinned model artifacts, request the retained suffix without depending on CDN ETag stability; verify the complete size and SHA-256 before installation. Retain the strict repeated strong validator rule for artifacts without a digest. An explicit active Cancel discards the checkpoint. Use the existing private downloader; do not introduce a permission or transfer service.

## Dictation dialog

Every Utterlane-owned dictation entry point uses one native recording panel and one phase-aware session controller: voice-intent and voice IME, floating microphone, accessibility shortcut, and the onboarding practice button. The Settings gear is mandatory, to the right of the listening heading. Preserve the confirmation contract: keep recording or explicitly discard during capture; while processing, return to transcription or transfer the same attempt durably to the queue before opening Settings. Android window hosts and ordinary transcript destinations remain separate; the practice trial still fills its practice field and preserves its duration cap. The separate Home recording workspace already has Settings, and Utterlane cannot change a third-party app's own recognizer dialog.

## About

Add **About** to the existing Settings directory. Display Utterlane, its actual installed version, project maintainer Stephen Karl Larroque, Apache-2.0, and a link to the GitHub repository. Credit the TranSlander lineage. State “Free and open-source software, made with love ❤️” and explain that all speech processing happens on-device and that model downloads and external links use the internet. Do not make network requests when opening About itself.
