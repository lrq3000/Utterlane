A clearer wait. More room to read.

Three progress treatments for the transcription dialog. Which feels most helpful while you read?

3 concepts · Based on dialog D
Illustrative values and text · No audio is processed
Progress means transcribed audio.The percentage follows completed speech processing, not how much of the file has been decoded. Finalizing remains a separate, honest stage.
Approximate, never pretend-precise.Show a completion ETA only when measurable. Otherwise say “Estimating time…” or name the active stage. No countdown to a false zero.
The text remains the main event.A persistent status area stays outside the scrollable text. Incoming segments must preserve the reader’s position; controls stay within reach.
